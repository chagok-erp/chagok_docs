## 2. P0 기능 수는 동일하며 일부는 방향 확정·세부 설계만 남은 사항

다음 항목은 **기능 목록을 늘리지 않고** 기존 기능의 수용 조건을 구체화해야 하는 과제다.

| 우선 | 항목 | 영향 기능 | 필요한 결정 |
|---|---|---|---|
| 높음 | PR과 PO 관계 | PR-01/02, PO-01/03 | **PR 1:N PO, PO당 공급업체 1곳 확정 방향.** PR 품목별 발주량 합계·락·멱등 제약은 ERD/API에 구현 |
| 높음 | 수량·가격·단위 정책 | MAT-01, PR-01, PO-01, GR-01, ST-01 | 품목 기준단위+Decimal·KRW·환산 제외 수용, 정밀도와 반올림 명세 필요 |
| 높음 | PO↔GR 품목 ID·트랜잭션 | PO-03, GR-01/02, ST-01 | 참조 키, 멱등 요청키, 잠금 순서, 입고 중 오류 롤백 |
| 높음 | 역할별 권한 | SEC-01/02, PR-02, APR-01, GR-01 | 같은 사용자가 요청자·승인자 겸직 가능한지, 창고 접근 경계 |
| 중간 | 초기 재고·현재고 정책 | WH-01, ST-01 | 초기고/재고 시드와 StockMovement 일치 방식 |
| 중간 | 재고 부족 판정 | AG-02, MAT-01, ST-01 | P0 사용자 지정 임계값 수용, 임계값 없으면 재질문 |
| 중간 | AI↔PR 저장 계약 | PR-01, AG-04/05, DOC-04 | 명령 중복방지·초안 수정 버전·오류 DTO |
